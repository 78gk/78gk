# 1-Week Outreach Script Pack (Copy/Paste)

Use these scripts to attract contributors quickly during your 7-day sprint.

## 1) Direct DM to a Technical Peer

Hey [Name] — I’m running a 7-day OSS sprint on [Repo].  
I opened a few tightly scoped issues that should each take ~1–2 hours:
- [Issue Link 1]
- [Issue Link 2]

If one fits your interests, I’d really value a contribution.  
I’m reviewing fast (same day / <24h) and can support with context quickly.

## 2) Community Post (Discord/Reddit/Slack)

I’m maintaining [Repo], an open-source [one-line project description].  
This week I’m running a contributor sprint and posted beginner-friendly tasks:
- [Issue Link 1]
- [Issue Link 2]
- [Issue Link 3]

If you want to contribute, I’ll provide quick support and rapid reviews.  
PR turnaround target: under 24h.

## 3) X / LinkedIn Short Post

Running a 7-day open-source sprint on [Repo].  
Looking for contributors for small, concrete issues (1–2h each).  
Fast review cycle (<24h) + clear acceptance criteria.

Contribute here: [Repo Link]  
Starter issues: [Issue Link List]

## 4) Follow-Up Message to Interested Contributor

Thanks for jumping in on [Repo]!  
Best starter issue right now: [Issue Link].  
Acceptance criteria are listed in the issue; if you want, I can also suggest the quickest implementation path.

If you open a draft PR early, I can review incrementally.

## 5) PR Review Thank-You Message

Thanks for the contribution — this is valuable and well-scoped.  
I merged your PR here: [PR Link].  
If you want another one, these are currently open and contributor-friendly:
- [Issue Link 1]
- [Issue Link 2]

## 6) Maintainer Update Post (Evidence Building)

Week sprint update for [Repo]:
- External PRs merged: [X]
- New contributors: [Y]
- Issues closed: [Z]
- New release/docs shipped: [Link]

If you want to contribute, starter issues are here: [Link].

---

## Outreach Execution Notes

- Always send issue links, not general “please contribute” requests.
- Keep asks small and specific.
- Reply quickly; speed is your conversion advantage.
- Publicly thank contributors to encourage repeat contributions.
