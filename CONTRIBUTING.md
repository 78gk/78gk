# Contributing

Thanks for considering a contribution.

## Fast Start

1. Open an issue (or pick an existing `good first issue` / `help wanted` issue).
2. Confirm scope and acceptance criteria in the issue thread.
3. Open a PR early (draft PR is welcome).
4. Keep changes scoped to one issue.

## PR Guidelines

- Reference the issue in your PR description.
- Explain what changed and why.
- Keep PRs small and focused.
- Update docs if behavior or usage changed.

## Review Expectations

- Maintainer review target: **under 24 hours** during sprint windows.
- You may receive iterative feedback for clarity and maintainability.

## Good First Contributions

Great first contributions include:
- documentation clarity improvements,
- setup/quickstart fixes,
- small scoped feature or bug tasks listed in issues.

## Communication

If you are blocked, comment on the issue/PR with:
- what you tried,
- where you are stuck,
- what decision/input you need.
